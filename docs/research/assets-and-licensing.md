Replacement approach: editable project-created SVGs with a 144×144 coordinate system, consistent strokes, white controls and mint active accents, gray inactive states, generic playlist/metadata symbols, and distinct repeat modes. PNG renditions retain encoder/OpenDeck compatibility: controls/plugin icon at 72×72 and 144×144; category at 28×28 and 56×56. All 23 SVG sources and 46 PNGs are committed; only PNGs and the asset notice enter the package. Shipping both formats under an extensionless manifest basename caused 36 ambiguous-resource warnings in CLI 1.10.1, so package only one rendition family and use PNG for dynamic Repeat images too. This follows the Stage 6 raster-feedback finding and avoids depending on a host's format precedence. The distributable binary is ignored. Preserve the original MIT `LICENSE` byte-for-byte and include it plus an asset notice in every package. No third-party icon-set attribution is required because none is imported.

Assumptions/limits: simple symbols are reviewed visually and created from basic geometry, not traced from a third-party icon set. Legacy asset provenance remains unknown; replacing it avoids relying on that unknown. No artwork or user-provided playlist images are bundled. Users remain responsible for images they select. Source review and rendering are not physical key/dial readability acceptance.

## Final inventory and validation

The original 32 inherited PNGs (16 basename groups) are all replaced, not reused. No inherited graphic is asserted to have proven individual authorship; its overall repository MIT notice is preserved. Stage 4's five known project-created state SVGs remain redistributable geometry and are refreshed consistently. Removed current-tree PSD/thumbnail remain in upstream history.

`scripts/generate-icons.py` defines all **23** editable shapes: `music-{play,pause,next,prev}`, `{like,dislike}-{off,on}`, `volume-{on,mute,up,down}`, `shuffle`, `shuffle-{off,on}`, `repeat`, `repeat-{none,all,one}`, `playlist`, `action-image` (quiet corner Track Info symbol), `category-icon`, and `plugin-icon`. Like/Dislike use whole/broken hearts; white/mint/gray states and repeat cross/two dots/one symbols remain distinguishable without relying solely on text. `icons/NOTICE.md` records project MIT provenance; no icon font, traced brand mark or third-party set is imported. Category and plugin music symbols are original geometry, not Pear's logo.

Generation uses Python 3 and **Inkscape 1.4.4 (`dcaf3e7d9e`, 2026-05-05)** with an isolated temporary profile/cache. Run `python3 scripts/generate-icons.py`; ordinary build copies the committed PNGs without requiring Inkscape. All renditions were rendered and visually inspected together on a dark background. Actual 72-pixel key and 200×100 dial legibility still needs hardware tests. The package audit verifies every PNG signature, category 28/56 and control 72/144 sizes, complete pairs, distinct state bytes, referenced resources and MIT/notice inclusion. Original MIT SHA-256 remains `c823e8c0ab3d6e53682d42507552e9e959acd06d6f6cda5f04f4ec605c3313db`.
